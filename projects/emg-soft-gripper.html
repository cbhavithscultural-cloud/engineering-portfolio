04 / SOFT ROBOTICS · SIMULATION

An EMG-informed soft gripper concept.

A SOFA simulation concept that connects an EMG-inspired input pipeline to grip-state logic for a three-finger PneuNet soft gripper. The current signal is synthetic and is used to exercise the software pathway.

SOFA FrameworkPythonSynthetic EMGRMS featureHysteresisPneuNet

01 / Simulation concept

The project models a three-finger soft PneuNet gripper and a virtual object in SOFA. The goal is to explore how a biosignal-inspired control input might map to a soft actuator command inside a simulation.

02 / Input and feature extraction

The current script generates a synthetic EMG-like waveform using a 20 Hz carrier, stage-dependent amplitude levels and noise. A 100 ms RMS window is calculated at a 100 Hz sample rate to produce a smoothed activation feature.

03 / Grip-state mapping

The RMS feature is mapped through LOW, MEDIUM and HIGH activation states with threshold/hysteresis logic. These states select simulation pressure commands of 0, 0.25 and 0.4 respectively. These are simulation command values, not calibrated physical pressure measurements.

04 / What this demonstrates

The prototype connects a signal-generation stage, feature extraction, discrete state logic and a simulated soft-actuator response. It is useful for testing control architecture and visualising the interaction between activation level and gripper behaviour.

05 / Limitations and next work

No live EMG sensor acquisition or physical pneumatic prototype is claimed. Future work should acquire real EMG safely, establish subject-specific calibration, quantify classification performance, validate pressure-to-deformation behaviour and test grasp repeatability on a physical setup.
