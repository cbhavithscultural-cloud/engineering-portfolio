01 / EMBEDDED ROBOTICS · HARDWARE PROJECT

SENTRY: an embedded autonomous mobile robot.

A microcontroller-centred mobile robot integrating sensing, motor actuation, inertial measurements, wheel encoder feedback and wireless telemetry. The project explores how low-level firmware coordinates physical behaviour under real-time constraints.

STM32F407FreeRTOSHC-SR04MPU6500TIM2 / TIM3ESP32-C3

01 / System architecture

The STM32F407 is the primary controller for motor PWM, ultrasonic ranging, IMU acquisition, encoder sampling and robot decision logic. An ESP32-C3 receives UART telemetry and serves a lightweight Wi-Fi dashboard. The controller and telemetry roles are kept separate so that communication does not become the primary motor-control loop.

02 / Sensing and actuation

Two front HC-SR04 sensors support forward obstacle detection and directional scanning; a rear sensor provides reverse-clearance information. An MPU6500 supplies inertial measurements, while timer encoder interfaces sample wheel motion. Motor PWM is generated through timer channels, and a servo positions the scanning sensor.

03 / Firmware behaviour

The firmware samples encoder counters, reads range measurements and integrates gyro-Z for a basic yaw estimate. The obstacle response uses distance thresholds to continue forward, scan left/right, select a clearer direction, or reverse only when rear clearance is sufficient. UART telemetry is sent to the ESP32-C3.

04 / Engineering observations

The implementation exposes practical embedded challenges: blocking ultrasonic timing, gyro drift, encoder rollover and direction handling, speed calibration, and robust telemetry framing. The current proportional encoder correction should not be described as a fully tuned PID speed controller. These are explicit next-step validation items.

05 / Validation boundary

This is a physical hardware project. Performance figures, calibrated speed accuracy, long-duration reliability and safety behaviour should only be added after repeatable bench and floor testing with recorded measurements.
