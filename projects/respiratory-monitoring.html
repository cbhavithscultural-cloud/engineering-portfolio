03 / BIOMEDICAL SIGNAL PROCESSING · OFFLINE DATA RESEARCH

Respiratory monitoring through signal analysis.

An offline respiratory-signal analysis workflow using the PhysioNet BIDMC PPG and Respiration dataset. The project investigates filtering, breath-event detection, annotation matching and machine-learning baselines.

PythonPhysioNet BIDMC125 HzSciPyPandasScikit-learn

01 / Dataset

The workflow uses the BIDMC PPG and Respiration dataset. The inspected recordings contain respiratory and physiological waveform channels sampled at 125 Hz, with breath annotations supplied separately. The dataset is used offline; it is not a live wearable data feed.

02 / Signal processing

The baseline pipeline applies a fourth-order Butterworth band-pass filter with a 0.1–0.7 Hz passband, then detects candidate respiratory peaks using SciPy find_peaks. A minimum peak separation and prominence threshold reduce implausible detections. Event matching uses a Hungarian assignment with a 0.75-second tolerance.

03 / Example recording result

For BIDMC recording 01, the pipeline detected 170 breathing peaks and estimated 21.26 breaths per minute. The detected events matched the available annotations for that recording under the configured matching tolerance. This single-recording result must not be generalized to the full dataset.

04 / Model comparison

The repository includes feature-based machine-learning experiments and cross-validation comparisons against a signal-processing baseline. In the current recorded evaluation, the baseline performed better on the reported MAE than the tested tree-based models. The result is a reason to investigate features, splits and generalization—not a claim that ML improves respiratory-rate estimation.

05 / Limitations and intended use

This is a research and prototyping workflow based on an existing dataset. It is not a medical device, diagnostic system or clinically validated monitor. Dataset bias, annotation uncertainty, subject-level leakage and independent validation remain important considerations.
